{%- comment -%} pptx-embed.html – embed a real .pptx file stored in this repo, using Microsoft's free Office Online Viewer. This works with no conversion step because GitHub Pages serves the .pptx at a real public HTTPS URL that the viewer can fetch and render slide-by-slide in an iframe. Usage, anywhere inside a post or page's Markdown body: {% include pptx-embed.html src="/assets/pptx/reading-workshop-slides.pptx" title="Reading Workshop – Slide Deck" %} Params: src required. Path from the site root, starting with "/". Put the actual .pptx file under assets/pptx/ (any filename is fine). title optional. Used as the iframe's accessible title. Note: the viewer needs to reach the file over the public internet, so this won't show a live preview on localhost — it'll still work once deployed to kitabomori.github.io. The download link below the embed always works, everywhere, as a fallback. {%- endcomment -%} {% assign pptx_url = site.root_url | append: include.src %}
